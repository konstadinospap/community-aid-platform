**Community Aid Platform**

**A web-based application developed as part of a university project at the University of Patras.**

The platform is designed to support the coordination and management of humanitarian aid, allowing citizens, rescuers, and administrators to interact through a centralized system.

**Key Features**

User registration and management

Submission and management of aid requests and offers

Inventory and resource management

Rescuer and administrator dashboards

Statistical data visualization

**Technologies Used**

PHP | MySQL | HTML | CSS | JavaScript
